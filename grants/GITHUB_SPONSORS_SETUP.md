# GitHub Sponsors Setup Guide

GitHub Sponsors lets users donate to your project. To enable:

1. **Settings**: https://github.com/sponsors/Mafengwo292
2. Click "Join the waitlist" or "Set up GitHub Sponsors"
3. Add bank account (PayPal or Stripe)
4. Choose sponsorship tiers

We can't do this from sandbox without:
- Browser session
- Bank account verification
- 2FA code from email

**Once enabled, add to README:**
```markdown
[![Sponsor me on GitHub](https://img.shields.io/badge/sponsor-♥-ff69b4)](https://github.com/sponsors/Mafengwo292)
```

**Tiers to consider:**
- $5/mo - Friend tier (name in README)
- $25/mo - Supporter tier (logo + early access)
- $100/mo - Sponsor tier (priority support, monthly call)
- $1000/mo - Enterprise (custom integration)

Note: Bank account can be added later via webhook. The user just needs to log in via browser once.
