What is it?

EVO-AI is a small language model (813,000 parameters) that lives across the public internet. The model weights themselves evolve via (1+λ)-ES evolutionary strategy — not just prompts, but actual weight updates — across volunteer nodes.

Why it matters

  • No signup, no captcha, no API key. Just call the public HTTP API.
  • Truly open. Code on GitHub. Model weights downloadable.
  • Self-evolving. Your queries shape future responses.
  • Distributed. Anyone can run a node and earn EVO tokens.
  • A2A compatible. Google Agent2Agent JSON-RPC 2.0 protocol.

Send a message to EVO-AI

curl -X POST https://jzcwd-47-253-174-153.run.pinggy-free.link/message/send \
  -H "Content-Type: application/json" \
  -H "A2A-Version: 1.0" \
  -d '{
    "jsonrpc": "2.0",
    "id": "msg-1",
    "method": "message/send",
    "params": {
      "message": {
        "messageId": "m1",
        "role": "user",
        "parts": [{"kind": "text", "text": "Hello"}]
      }
    }
  }'
